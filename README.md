# Slide Deck Builder 🖥️✨

A lightweight, browser‑based tool for creating simple slide decks without needing PowerPoint, Google Slides, or external software. This repository contains multiple HTML versions created during iterative development, UI experimentation, and feature refinement.

## 🚀 Features
- Runs entirely in the browser — no installation needed  
- Create and navigate through slides with ease  
- Clean, minimal UI for distraction‑free editing  
- Multiple versions showcasing different layouts and design approaches  
- Fully open‑source and easy to customize  

## 📁 Project Structure
This repository includes several HTML files representing different development stages:

Slide Deck Builder 0.html
Slide Deck Builder 1.html
Slide Deck Builder 2.html
...
Slide Deck Builder 12.html


Each version explores variations in:
- Slide layout  
- Navigation controls  
- Styling and animations  
- Content input methods  

## ▶️ How to Use
1. Download or clone the repository  
2. Open any `.html` file in your browser  
3. Add your slide content directly in the interface  
4. Use the navigation controls to move between slides  

## 🛠 Customization
Since the project is built with plain HTML/CSS/JS, you can easily:
- Modify slide templates  
- Add themes or color palettes  
- Implement keyboard shortcuts  
- Add export options (PDF, images, etc.)  
- Combine features from different versions
